# Documentation

- `decisions/`: accepted architecture decisions
- `guides/`: reusable project and UI guidance
- `planning/`: feature specifications, plans, and task records
- `reports/`: generated or point-in-time review reports
- `research/`: external product and pharmacy research
- `data/`: notes about imports, normalization, and unmatched data
- `ATTRIBUTIONS.md`: third-party source and asset attribution

Planning documents may describe historical paths when they record completed migrations. Current placement rules are defined in `decisions/001-vite-feature-architecture.md`.
